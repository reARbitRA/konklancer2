# Active route map

Hash URLs support standalone clients. `#/` overview; `#/opportunities` discovery; `#/opportunities/:id` detail; `#/pipeline` stage list; `#/studio` and `#/studio/:id` editor; `#/insights` outcomes; `#/settings` account, provider and scan operations. Basic legacy aliases redirect `#/hunt`, `#/analytics`, `#/ops`, `#/login` and `#/account` to their closest new destinations. Redirects do not imply feature parity with those legacy pages.

Discovery query parameters include `q`, `view`, `source`, `page`; pipeline supports `stage`. Existing legacy deep-link query semantics require further verification.
