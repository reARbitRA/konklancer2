# اپ اندروید کنکلنسر

این پروژه یک پوسته‌ی سبک Capacitor است که رابط وب کنکلنسر را در Android WebView باز می‌کند. خودِ اسکنر و API روی سرور اجرا می‌شوند؛ APK به‌تنهایی اسکن آفلاین انجام نمی‌دهد.

## ساخت APK

از GitHub Actions، ورک‌فلو **Build Android APK** را با آدرس HTTPS سرور اجرا کنید. خروجی `app-debug.apk` به‌صورت Artifact آماده‌ی دانلود می‌شود.

## محدودیت‌های نسخه‌ی پیش‌نمایش

- APK به آدرس سروری که موقع ساخت داده می‌شود وابسته است. اگر سرور پیش‌نمایش خاموش یا آدرسش عوض شود، APK هم به آن وصل نمی‌شود.
- APK کلید `KONKRED_API_KEY` را در خود ندارد؛ کلید باید فقط در `.env` سمت سرور بماند.
- این نسخه احراز هویت مستقل برای API ندارد. هرکسی که به نشانی سرور پیش‌نمایش دسترسی داشته باشد ممکن است endpointهای `/api/*` را فراخوانی کند؛ از این APK برای داده‌ی حساس یا انتشار عمومی استفاده نکنید.
