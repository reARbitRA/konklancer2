# Obsidian navigation shell

Approved by the operator's locked Obsidian Console direction and explicit instruction to implement it. This incremental specification covers the persistent navigation shell only; it does not claim that legacy feature surfaces are fully restyled.

- Keep all existing routes, job state, model controls, account controls and actions.
- Use a 56px command header, a collapsible 232px navigation rail, dark surfaces and lime focus/active signals.
- Provide responsive mobile navigation, keyboard access, visible focus, route identity, and live (not invented) feed/connection context.
- Preserve the existing hash router for Android and standalone distribution.
- Verify TypeScript, tests and build. Screen-level redesign and provider architecture migration remain separate work.
