# SPEC-003 — Safety & Hardening

## 1. Summary
رفع ریسک‌های امنیتی و حقوقی: انتشار عمومی کد، نشت توکن، پروژه‌های غیرمجاز، و APIهای بدون احراز هویت.

## 2. Behavioral Contract
### 2.1 Rules
- R1. مخزن ساخته‌شده از طریق اپ **پیش‌فرض خصوصی** است. انتشار عمومی فقط با تیک صریح کاربر و نمایش هشدار.
- R2. توکن GitHub فقط در `sessionStorage` نگه داشته می‌شود و هرگز در `localStorage` ذخیره نمی‌شود. (کلیدهای قدیمی `freelanceflow_settings.githubToken` هنگام بارگذاری پاک شوند.)
- R3. پیش از هر تحلیل، `analyze-job` محتوای پروژه را با قواعد بلاک‌لیست بررسی می‌کند (دور زدن کپچا، ضدربات، استخراج شماره تماس/داده شخصی، جعل مدرک یا هویت، نقض ToS). پروژه‌ی مشمول، `blocked: true` می‌گیرد و پیشنهاد/تحلیل تولید نمی‌شود.
- R4. داده‌های نمونه‌ی حاوی محتوای بالا از `DEFAULT_JOBS` و `mockJobs.ts` حذف می‌شوند.
- R5. همه‌ی مسیرهای `/api/*` به توکن `KONKLANCER_API_TOKEN` (هدر `Authorization: Bearer`) نیاز دارند. اگر متغیر تنظیم نشده باشد، سرور در حالت توسعه فقط به `127.0.0.1` گوش می‌دهد و هشدار می‌دهد.
- R6. `status: in_progress` دیگر مخزن را خودکار نمی‌سازد؛ ساخت مخزن فقط با دکمه‌ی صریح کاربر انجام می‌شود. (SPEC-001 نیز همین را باید تایید کند.)
- R7. `freelance_pro_engine.py` از مخزن حذف می‌شود (در تاریخچه گیت باقی می‌ماند).

## 3. Acceptance Criteria
- AC-1: Given فرم ساخت مخزن، when باز می‌شود، then گزینه‌ی پیش‌فرض «خصوصی» است.
- AC-2: Given توکن ذخیره‌شده، when صفحه بسته و باز شود، then توکن در `localStorage` وجود ندارد.
- AC-3: Given پروژه با عبارت «دور زدن کپچا»، when `analyze-job`، then پاسخ `blocked: true` با دلیل است.
- AC-4: Given درخواست بدون توکن به `/api/jobs` و `KONKLANCER_API_TOKEN` تنظیم‌شده، then پاسخ 401.
- AC-5: Given `status=in_progress`، when تغییر وضعیت، then هیچ درخواست GitHub ارسال نمی‌شود.

## 4. Non-goals
- احراز هویت کاربر نهایی (چندکاربره). فقط توکن سرویس.

## 5. Open Questions (تأیید بعدی کاربر)
- Q1: حذف `freelance_pro_engine.py` از مخزن؟ (تا پاسخ، فایل دست‌نخورده می‌ماند و اجرا نمی‌شود.)
- Q2: نام مدل‌ها (`gemini-3.8-flash` یا مدل دیگر)؟ (تا پاسخ، از متغیر محیطی با همین مقدار پیش‌فرض خوانده می‌شود.)
- Q3: R6 (حذف ساخت خودکار مخزن) — پیش‌فرض اعمال می‌شود چون در فهرست ایمنی کاربر بوده است.
